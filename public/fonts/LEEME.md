# Tipografías

- **Satoshi** (Indian Type Foundry, Fontshare Free Font License). Se sirve desde el propio Hosting (autoalojada).
  La licencia permite autoalojarla en tus propias webs pero **no redistribuir el archivo**, así que `Satoshi-Variable.woff2`
  está en `.gitignore` y no se sube al repositorio público. Para tenerla en local:
  descárgala en https://www.fontshare.com/fonts/satoshi y copia `Satoshi-Variable.woff2` aquí. Sin ella se usa la fuente del sistema.
- **JetBrains Mono** (SIL OFL) se instala con el paquete npm `@fontsource/jetbrains-mono`.
